# ML_project
"Trust Rank Assignment", and it involves implementing the Trust Rank algorithm using Python. This algorithm is typically used to rank web pages or nodes in a network based on trustworthiness, similar to how PageRank works but with added emphasis on trusted seed nodes.

How to set up and run your project ?

1.Install Python and Jupyter Notebook:

bash
pip install notebook numpy networkx

2.Launch Jupyter:
bash
jupyter notebook

3.Open assign1.ipynb, then run each cell using Shift + Enter.

Any dependencies or configuration required ?

✅ Dependencies:numpy
networkx
jupyter (to run the notebook)

🛠️ Configuration:
No special configuration is needed—just ensure the required libraries are installed before running the notebook.
